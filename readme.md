## Описание
Плагин ColorRegion предназначен для `цветовой разметки кода` в целях:
- повышения структурированности, 
- лёгкости чтения, 
- повышения удобства коммандой работы и т. д

Плагин ColorRegion v 0.0 поддерживает работу с `Clion` версии `2023.2.2`

Плагин позволяет выделить цветом **любые** строки **любого** файла в проекте **любым** цветом из палитры RGB-256

## Логика работы с v 0.0
Плагин предоставляет возможность выдлеить цветом любый блоки кода и текста.
При инициализации проекта будет создана директория `/.ColorRegion`, которая и является основной для данных плагина
Раскраска задаётся по следующим правилам:
### 1

---
```
Создаётся map.yml - карта для всех документов, которые необходимо раскрасить
В него мы добавляем записи вида <индекс: путь_к_файлу> (относительно директории проекта)
Нумерация индексов *строго подряд* с 0
```

Пример структуры `map.yml`
```YAML
0: "a.cpp" //За нулевым индексом закрепляется файл в директории проекта с именем <a.cpp>
1: "b.cpp" //За первым индесом - <b.cpp>
```

### 2

---
```
Для каждого файла создаётся <индекс>.yml - карта регионов для конкретного файла
В него мы добавляем записи вида <индекс: <start: начальная строка, end: конечная строка, color: цвет>
Нумерация индексов *строго подряд* с 0
```

Пример структуры `0.yml`
```YAML
0:
  start: 1
  finish: 3
  color: "#993300" //В файле под индексом 0 строки 1-3 красные
1:
  start: 14
  finish: 14
  color: "#01AF66" //строка 14 зелёная
```

### 3

---
Нарушение записи для конкретного региона в `<индекс>.yml` влечёт лишь его неотображение
Нарушение записи для файла в `map.yml` влечёт полное отсутствие в нём раскраски
